# thesis-MultifeatureApp

** Multi-Feature Eye-Driven Viewport **

A Python-based application developed as part of a diploma thesis at the University of Patras.

The application explores a vision-based approach to controlling a virtual camera's zoom level through real-time facial feature tracking.

Using a standard camera, the system analyses multiple facial characteristics, including pupil size, nose dimensions and interpupillary distance (IPD), to estimate changes in the user's relative distance from the screen.

By combining these measurements, the application provides a more stable and robust zoom control mechanism, enabling a more natural and intuitive interaction with virtual environments.

The project investigates the potential of multi-feature facial tracking for eye-driven viewport applications, with a focus on measurement stability, responsiveness and robustness.
